OSI MODEL:
Physical Layer - How big the cables are to hold 1/0 or frequency band for wireless - FCS(Frame Check Sequence) & Physical
Data Link Layer - Source & Destination MAC Address
Network Layer - Source & Destination IP Address
Transport Layer - Data (Multiple data blocks of max 1500 bytes each and Min of 64 bytes)
Session Layer - Establishing sessions with email/web servers using Source & Destination Port Numbers 
Presentation Layer - Makes sure that the data is in a format that the application can view
Application Layer - Smarts built into applications so that it can read the data

Preamble - Tells the Network Card that a frame is incoming. 
Pad - Extra data added incase the data being transmitted is less than 64 bytes in the ethernet frame. 
FCS(Frame check sequence)
CRC - Cyclic redundancy check 
Port numbers range from 0 - 65535
System ports 0 - 1023
Registered (User) Ports - 1024 - 49151
Dynamic(Ephemeral) ports - 49152 - 65535
Port number identifies to a network a specific Service/Protocol/Application that is to receive and process the incoming message 
Transport Layer Protocols (Layer 4) - IP & TCP & UDP
Layer 3 - ICMP - Used for communication b/w n/w devices. IPsec - Provides N/W security like VPN.

*N/W Troubleshooting Theory Steps*:

1. Identify the problem
2. Establish a theory of probable cause (Work on OSI model bottom up or top down)
3. Test the Theory
4. Establish a plan of action
5. Implement and test the solution
6. Verify system functionality 
7. Document findings
